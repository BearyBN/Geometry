# Geometry Dash — клон для Pythonista 3 (iOS)

Одиночный файл `geometry_dash.py`, написанный на модуле `scene` из Pythonista.
Никаких внешних библиотек и картинок не нужно — вся графика рисуется кодом.

## Запуск

1. Скопировать `geometry_dash.py` в Pythonista (например, в папку `This iPhone`).
2. Открыть файл и нажать ▶︎.
3. Держать телефон горизонтально — игра сама запрашивает landscape.

Прогресс (лучший процент по каждому уровню) сохраняется в
`~/Documents/geometry_dash_save.json`.

## Управление

| Действие | Что делает |
|---|---|
| Тап в любом месте | Прыжок |
| Удержание | Прыгает сразу при каждом приземлении и активирует орбы — как в оригинале |
| Кнопка **II** справа сверху | Выход в список уровней |

## Экраны

**Меню** — название, прыгающий кубик на земле, кнопка `START`.

**Выбор уровня** — карточка с номером, названием, «лицом» сложности, звёздами,
лучшим процентом и мини-схемой начала уровня. Листается стрелками по бокам
или свайпом. Кнопка `PLAY` запускает уровень, `MENU` возвращает назад.

**Игра** — полоса прогресса сверху, текущий и лучший процент, счётчик попыток
(«Attempt N», как в оригинале), взрыв кубика и мгновенный рестарт при смерти.

## Уровни

14 уровней, названия, сложности, количество звёзд и цветовые схемы взяты у
официальных уровней Geometry Dash — от `STEREO MADNESS` (Easy, 1★) до
`CLUBSTEP` (Demon, 14★). Каждый уровень собирается из «паттернов» с личным
зерном генератора, поэтому:

* **строение уровня постоянно** — уровень 3 всегда выглядит одинаково;
* **все уровни разные** — у каждого свой набор паттернов, своя плотность,
  своя длина и своя палитра.

Набор препятствий:

| Объект | Поведение |
|---|---|
| **Шип** | Смерть при касании. Хитбокс заметно уже картинки. |
| **Блок / платформа** | Безопасная поверхность. На неё запрыгивают, чтобы с высоты перелететь поле шипов, которое с земли не перепрыгнуть. Удар в бок — смерть, но у самой кромки игрока «подсаживает» наверх. |
| **Орб** (жёлтое кольцо) | Прыжок прямо в воздухе. Позволяет перелетать поля из 6-9 шипов и связывается в цепочки. |
| **Пад** (жёлтая площадка) | Срабатывает сам, подбрасывает выше обычного прыжка. |

## Почему всё проходится «с запасом»

Физика подобрана так, чтобы прыжок был заметно длиннее и выше минимально
необходимого:

* длина прыжка — **5.37 блока**, максимальное поле шипов без помощи — **3 блока**;
* высота прыжка — **3.11 блока**, платформы стоят на высоте 1-2 блока;
* хитбокс шипа — 0.48 × 0.6 блока вместо 1 × 1, хитбокс игрока — 0.58 вместо 0.9;
* буфер прыжка 0.16 с (нажатие до приземления не теряется);
* «койот-тайм» 0.12 с (можно прыгнуть чуть позже края);
* если игрок чуть-чуть не допрыгнул до верха блока — его подсаживает наверх,
  а не убивает;
* зона срабатывания орба (±1.15 × ±1.25 блока) намного больше самого кольца;
* площадки для приземления — 3-4 блока шириной, то есть окно приземления
  около 0.4 секунды.

Отдельное правило генератора: два препятствия, каждое из которых требует
своего прыжка, никогда не стоят ближе 6 блоков друг к другу. Иначе каждое
приземление «съедало» бы запас по времени (прыжок нельзя укоротить), и после
нескольких таких прыжков подряд участок становился бы непроходимым в принципе.

## Проверка уровней

Уровни проверены не на глаз: физика вынесена в класс `World`, не зависящий от
графики, поэтому её можно гонять без iOS. В разработке использовались:

* **beam search** по всем моментам прыжка — доказывает, что каждый из 14
  уровней проходится до 100 %;
* **замер окна** каждого прыжка — на сколько кадров раньше и позже можно
  нажать, чтобы уровень всё ещё проходился.

Результаты замера (60 кадров в секунду): среднее окно прыжка — **19-24 кадра
(0.3-0.4 с)**, минимальное на большинстве уровней — 11-19 кадров. Уровни с
сериями висящих платформ показывают в этом замере узкие окна, но только
потому, что поиск выбирает экзотическую линию (пролететь платформу насквозь,
прыгнув на последнем кадре «койот-тайма»). Естественная линия там гораздо
шире: если на подходе к такой секции просто **зажать кнопку**, кубик сам
перепрыгивает с платформы на платформу, и зажать её можно в окне около
3.7 блока (~0.45 с).

Первый прогон поиска нашёл реальную ошибку дизайна: шесть одиночных шипов с
шагом 4 блока при длине прыжка 5.37 — каждое приземление съедало запас, и
участок был непроходим в принципе. Правило про минимум 6 блоков между
препятствиями появилось именно из-за неё.

## Структура кода

```
физика и константы      SPEED / GRAVITY / JUMP_V, хитбоксы, запасы
LEVELS                  14 уровней: имя, сложность, звёзды, палитра, паттерны
паттерны                pat_single … pat_orbchain — кусочки уровня
build_level(i)          сборка уровня по фиксированному зерну
World                   чистая симуляция без графики (её же гоняет проверка)
tex_*                   генерация всех текстур через ui.ImageContext
GeometryDash(Scene)     экраны меню / выбора уровня / игры
```
